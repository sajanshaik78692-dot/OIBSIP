\# Voice Assistant (Advanced Tier)



\## Features

\- Voice input capture via `speech\_recognition`

\- Text-to-speech output using `pyttsx3`

\- Web searching capabilities

\- Real-time time \& date responses

\- OpenWeatherMap API integration for live weather checks

\- Email sending functionality via `smtplib`



\## Setup \& Dependencies

```bash

pip install speechrecognition pyttsx3 requests pyaudio
